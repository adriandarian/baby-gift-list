One-time setup needed

The manager is built, but secure saving needs a GitHub access token and two private Vercel settings. No gift data has been changed.

In the Vercel project's Settings → Environment Variables, add GITHUB_REGISTRY_TOKEN, REGISTRY_ADMIN_PASSWORD, and REGISTRY_SESSION_SECRET for Production. Redeploy after adding them.

Make the GitHub token fine-grained, limited to the baby-gift-list repository with Contents: Read and write. Use a strong password (16+ characters) and a separate randomly generated session secret (32+ characters). Never paste them into the public repository.
